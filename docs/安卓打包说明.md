# 安卓打包说明

本项目同时支持网页端部署和 Capacitor Android 打包。

网页端部署继续使用：

```bash
pnpm build
```

Android 打包使用专用模式：

```bash
pnpm android:build
```

Android 模式会使用 hash 路由，避免 WebView 或静态资源环境里刷新路径失败；网页端默认仍使用 history 路由。

## 推荐方式：加载内网 HTTP 站点

如果后端仍然使用 Cookie 登录态，推荐把前端静态资源和后端 `/api` 部署到同一个内网 IP 下，例如：

```text
http://192.168.1.10/
http://192.168.1.10/api
```

然后在项目根目录新建 `.env.android`：

```env
VITE_ANDROID_SERVER_URL=http://192.168.1.10
```

生成并同步 Android 工程：

```bash
pnpm install
pnpm android:build
pnpm cap:open:android
```

## 只打包本地前端资源

如果不配置 `VITE_ANDROID_SERVER_URL`，APK 会加载打包后的本地 `dist`，并允许 HTTP 明文请求。此时需要在 `.env.android` 中配置完整 API 地址，例如：

```env
VITE_API_BASE_URL=http://192.168.1.10:8850/api
VITE_ROUTER_MODE=hash
```

注意：这种模式下前端页面和 API 不是同源，Cookie 登录态可能受 Android WebView 和后端 Cookie SameSite 策略影响。若登录不稳定，请改用上面的“加载内网 HTTP 站点”方式。

## 打包 APK

Android Studio 打开 `android/` 后，使用 `Build > Generate Signed Bundle / APK` 生成签名 APK。内部少量用户使用时，可直接安装 APK。
